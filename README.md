# Basic Employee Onboarding (AD)(RBAC)

## Project Summary
I created an Active Directory environment for a fictional company, establishing Organizational Units (OUs) for Finance, HR, IT, and Operations. I created user accounts and department-specific security groups to organize users and manage resource access. Simulated a help desk ticket involving a user who could not access the appropriate resources due to incorrect department assignment. I investigated and resolved the issue by correcting the user's security group membership and moving their account to the correct OU. This project gave me hands-on experience with Active Directory administration, user and group management, access control, and IAM troubleshooting to practice for real scenarios I will encounter throughout my IT career.
